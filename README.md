# AI-Enhanced Resume Builder

An AI-powered Resume Builder built with the MERN stack that helps users create professional and ATS-friendly resumes with a real-time preview and smart AI-assisted summary generation.

## 🚀 Live Demo

🔗 https://resume-ai-beryl-gamma.vercel.app/

## 📌 Features

* Create professional resumes effortlessly
* Real-time resume preview
* AI-assisted summary generation
* Responsive and modern UI
* State management using Redux
* Dynamic form handling
* MongoDB database integration
* RESTful APIs for data management
* ATS-friendly resume structure

## Installation

### Clone the repository

```bash
git clone https://github.com/deveshgi/portfolio.git
```

### Navigate to the project

```bash
cd portfolio
```

### Install dependencies

```bash
npm install
```

### Start the development server

```bash
npm run dev
```
